## Branch & PR Convention
- **No Direct Pushes to Main**: After the initial repository setup, direct pushes to the `main` branch are restricted.
- **Branching**: Create feature or bugfix branches off of `main` for all work.
- **Pull Requests**: Open a Pull Request (PR) when your branch is ready to be merged.
- **Review and Approval**: Each PR must be reviewed and approved by at least one other team member before it can be merged into `main`.
- **Committing Identity**: Since contribution is graded weekly based on repository activity, it is strictly required that you always commit using your own identity (your name and email configured in Git).
